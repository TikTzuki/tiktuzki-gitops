⚠️  pgdog serves stale reads by design
────────────────────────────────────
read_write_split is "{{ .Values.pgdog.readWriteSplit }}".
{{- if eq .Values.pgdog.readWriteSplit "include_primary" }}
Replication is asynchronous, so a read in a SEPARATE transaction right after a write can land
on a replica that has not replayed it. Reads inside the writing transaction are safe. For any
service where a stale read is a correctness bug — idempotency probes, saga state,
read-after-migrate — set pgdog.readWriteSplit=prefer_primary.
{{- end }}
{{- end }}
